# 尼康 F90X/F90 操作指南

简体中文 HTML 版操作指南（117 个主题），由原版 WinHelp 转换而来。

## 在线阅读

若已启用 [GitHub Pages](https://pages.github.com/)，打开：

**https://kuixiaoran.github.io/F90X-Handbook_zh_CN/**

深链接示例：

```
https://kuixiaoran.github.io/F90X-Handbook_zh_CN/#topic/f90j.t008e1b
```

## 本地打开

克隆仓库后，用浏览器打开 `index.html`（支持 `file://`）。

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 完整阅读器（目录 + 正文 + 搜索） |
| `embed.html` | 嵌入模式入口（`?embed=1`） |
| `help-data.js` | 主题数据 |
| `assets/f90j/` | WebP 图标与插图 |
| `assets/branding/` | Nikon / F90X 标识 |
